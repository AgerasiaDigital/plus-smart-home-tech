# Smart Home Tech

Платформа для управления умным домом и коммерческой инфраструктурой, построенная на микросервисной архитектуре с использованием Spring Boot, Spring Cloud и Apache Kafka.

## Модули

Проект разделён на три основных модуля:

### Telemetry (Телеметрия)

Отвечает за сбор, агрегацию и анализ данных с устройств умного дома в реальном времени.

- **Collector** — принимает события от датчиков и хабов по HTTP и gRPC, публикует их в Kafka
- **Aggregator** — потребляет события из Kafka, строит актуальные снапшоты состояния датчиков и публикует их обратно в Kafka
- **Analyzer** — читает снапшоты и события хабов, проверяет условия сценариев и отправляет команды устройствам через gRPC (Hub Router)

Сериализация событий реализована через Apache Avro (avro-schemas) и Protocol Buffers (proto-schemas).

### Commerce (Коммерция)

Реализует полный цикл обработки заказов интернет-магазина.

- **Shopping Store** — каталог товаров с пагинацией и управлением состоянием
- **Shopping Cart** — корзина пользователя с circuit breaker для взаимодействия со складом
- **Warehouse** — управление складскими остатками, бронирование и сборка заказов
- **Order** — оркестрация жизненного цикла заказа
- **Payment** — расчёт стоимости и управление платежами
- **Delivery** — планирование и отслеживание доставок
- **Interaction API** — общие DTO и Feign-клиенты для межсервисного взаимодействия

### Infra (Инфраструктура)

- **Discovery Server** — Eureka-сервер для регистрации и обнаружения сервисов
- **Config Server** — централизованное хранение конфигураций всех сервисов (Spring Cloud Config, native profile)
- **API Gateway** — единая точка входа, маршрутизирует запросы к нужным сервисам через Spring Cloud Gateway

## Технологии

| Слой | Технологии |
|---|---|
| Фреймворк | Spring Boot 3.3, Spring Cloud 2023.0 |
| Сервис-дискавери | Netflix Eureka |
| Конфигурация | Spring Cloud Config |
| Межсервисное взаимодействие | OpenFeign, gRPC |
| Отказоустойчивость | Resilience4j Circuit Breaker |
| Стриминг | Apache Kafka |
| Сериализация | Apache Avro, Protocol Buffers |
| БД | PostgreSQL + Spring Data JPA |
| Инфраструктура | Docker Compose (Kafka) |

## Архитектура

```
                        ┌─────────────────┐
                        │   API Gateway   │ :8080
                        └────────┬────────┘
                                 │
          ┌──────────────────────┼──────────────────────┐
          │                      │                      │
   ┌──────▼──────┐        ┌──────▼──────┐       ┌──────▼──────┐
   │   Order     │◄──────►│  Payment    │       │  Delivery   │
   └──────┬──────┘        └─────────────┘       └─────────────┘
          │
   ┌──────▼──────┐        ┌─────────────┐
   │  Warehouse  │        │Shopping Cart│
   └─────────────┘        └─────────────┘

   ┌─────────────┐   Kafka   ┌─────────────┐   Kafka   ┌─────────────┐
   │  Collector  ├──────────►│ Aggregator  ├──────────►│  Analyzer   │
   │ HTTP / gRPC │           └─────────────┘           └──────┬──────┘
   └─────────────┘                                            │ gRPC
                                                       ┌──────▼──────┐
                                                       │ Hub Router  │
                                                       └─────────────┘
```

Все коммерческие сервисы регистрируются в **Eureka**, получают конфигурацию из **Config Server** и общаются друг с другом через **Feign**-клиенты с балансировкой нагрузки.
